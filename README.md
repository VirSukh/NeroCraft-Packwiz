# NeroCraft Packwiz

Sorgente privata del modpack NeroCraft per Minecraft 1.21.1 e NeoForge 21.1.266.

Questo repository contiene l'indice Packwiz, le configurazioni condivise, KubeJS,
le quest e i metadati delle mod. Le chiavi, i token e i file personali non devono
essere aggiunti al repository.

La distribuzione agli amici viene pubblicata separatamente su un endpoint pubblico
compatibile con Packwiz; il repository sorgente rimane privato.
